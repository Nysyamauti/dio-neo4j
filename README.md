# My journey through DIO Bootcamp: Neo4j - Certification

## About
The **Neo4j Certification Bootcamp** by DIO focuses on the Neo4j native graph database, guiding students from fundamental concepts and hands-on projects to achieving Neo4j certification.

## Repository
This repository contains projects, queries and study notes covering native graph database architeture, from core modeling and Cypher querying to practical implementations aimed at earning the official **Neo4j Certified Professional** credential.
